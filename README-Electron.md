# MINI68 离线配置（早期 Electron 版本）

本文描述本机自行构建的早期运行包，公开仓库不提供其中的官方网页资源或二进制包。

另有采用 Tauri + Rust + 系统 WebView2 的轻量单文件版本，见 [轻量版使用说明](README-Lite.md)。下文对应保留的 Electron 完整运行时版本。

适用于 Windows 10 / 11 64 位。基于狼蛛网页驱动的本地适配版，非官方发布。页面、设备定义、灯效算法和声音组件均已放在本机，使用时不需要联网，也不需要安装 Node.js、Python 或网页音乐插件。

## 使用

1. 将压缩包完整解压到一个固定文件夹，双击 `MINI68-Offline.exe`。必须保留同目录的 DLL、resources 等文件；不能只复制 EXE。
2. 使用 USB 数据线连接 MINI68，关闭其他正在连接该键盘的驱动页面，再点击“连接键盘”。本机实测识别为 **MINI68 HE MAX**。
3. 按键、宏、灯效、性能及高级键功能沿用原网页。修改后按原界面的“保存”操作。首次运行使用独立的本地配置，不会自动导入浏览器里的配置文件。
4. 音乐律动：进入 **灯效设定 → 音乐律动**，选择模式，播放电脑声音。可调整“振幅”以改变反应强度。
5. 保持音乐律动选项卡，点击窗口右上角 **×** 或按 **Ctrl+W**。窗口会收起到右下角托盘，音乐律动继续。无需保留浏览器窗口。
6. 双击托盘图标可重新打开；右键托盘图标选“退出”，或按 Ctrl+Q，才会完全退出程序。

音乐律动需要电脑持续读取声音并向键盘发送灯光数据，因此程序必须留在后台。退出、休眠、断开键盘，或切换到其他设置页面后，实时音乐灯效停止；重新打开音乐律动选项卡可恢复。本版没有设置开机自启。

## 声音与连接

- 读取 Windows **默认播放设备**的实时音量，不使用麦克风，不保存录音。音乐播放器应输出到同一默认设备；指定其他声卡或独占输出可能无法检测。
- 无反应时先检查声音播放、默认输出设备、键盘 USB 连接和“振幅”。声音组件依赖 Windows 自带的 .NET Framework 4.x。
- 已限定 MINI68 系列 USB 设备授权；其他型号、无线接收器、蓝牙未验证。
- 固件升级和在线社区未提供，云端素材等联网内容不可用。需要更新固件时使用官方工具。
- 音乐模式是原网页的音量驱动灯效，不是新增的独立频谱分析器。

## 验证范围

已验证本机 MINI68 HE MAX 的实际 USB 连接和配置读取；本地服务测试 9 项通过；页面无加载错误；Windows 实际播放音量可读取；窗口隐藏后仍能持续采样并生成灯效数据包。

自动验证拦截了灯效写入并模拟应答，未改写现有按键或灯光设置，也未刷固件。因此真实键盘灯光的最终视觉效果仍需打开音乐律动后观察。

## 源码与重建

源码在本项目目录，运行包中包含桌面应用源码和处理后的网页资源。首次构建需联网；运行无需联网。

开发依赖：Python 3、requests、Windows .NET Framework C# 编译器；测试额外需要 Node.js 与 Playwright。

```powershell
python -X utf8 scripts/download_resources.py
python -X utf8 scripts/build.py
node --test tests/server.test.cjs
node scripts/smoke.cjs --packaged
node scripts/music-check.cjs --packaged
```

硬件测试要求连接 MINI68 HE MAX，会播放两秒低音量测试音。构建固定使用 Electron 45.0.0 Windows x64，并验证下载包 SHA-256。网页快照来自 https://hec.aulacn.com/，资源清单和校验值见 `resource-manifest.json`。上游网页版本发生变化时，补丁锚点不匹配会停止构建，需要重新检查适配。

用户配置位于 `%APPDATA%\MINI68 Offline`。目录式便携包免安装，但配置保存在当前 Windows 用户目录，不随 EXE 文件夹移动。
